What does everything do?

- Top menu
    - System, Position, and QNH sections cannot be simulated on vatsim.
        - Replace with buttons for:
            - Connection menu (Settings -> Connection, button displays logon callsign when connected)
            - Position menu (Settings -> Position, clicking the button opens the menu, button displays position name as the menu bar currently does)
            - Visibility menu (Settings -> Visibility Centers, clicking the button opens the menu, button displays either AUTO or MAN)
            - Sector menu (Settings -> Sectors, clicking the button opens the sectors window)
            - Restricted airspace (Settings - > Restricted Areas, clicking the button opens the restricted airspace menu)
            - ATIS Editor (opens the ATIS Editor from the ATIS Editor plugin using reflection)
            - ATIS Window ()
    - Main Window section
        - Text box shows left-to-right distance visible in the main ASD, same as shown in the built-in menu bar
        - Border on the right shows:
            - CEN: ASD is centered
            - OFC: ASD is off-center
            - DEF: ASD is in the default position
            - STO: Position is stored
            - RST: Position is restored
        - Same goes for the Second Window section as above, but only for the first opened Air window
    - Display levels section
        - Same as Tools -> Filters -> Display Levels
        - Each field accepts 3-digits from 000 to 999.
    - SSR Code Filters section
        - Same as Tools -> Filters -> SSR Code
        - First two fields accept two digits from 0 to 7
        - Second two fields accept 4 digits from 0 to 7
    - Time section
        - The first text block displays the current UTC time
        - The second is a timer, dispaying `0000` by default
            - Clicking it opens the Time menu
            - Selecting a value starts the timer, same as the built-in menu
            - The button shows the time remaining until the timer activates.
    - Functional states
        - VEL: Toggle velocity vectors on or off
            - Clicking the button below it changes the length of the vector, clicking it opens a popup menu with values 1, 2, 3, 4, 5, 10, 15. 
        - SRP: Toggle Short Route Probe on or off
            - TODO
        - HIST: Toggle history dots on or off
            - The button below it changes the amount of history dots, same interaction as the VEL, and values sourced from Tools -> History Trails
        - SSR All: toggles on the "SSR Callsigns" function
        - QLK All: toggles qlk all function
        - FPAST: toggles FPASD, same as Tools-> FPASD
        - Normal: Toggles between normal and extended labels, button shows which is currently active, either "Normal" or "Extended"
        - Fixed: Toggles between Fixed or Shared labels. button shows which is currently active, either "Fixed" or "Shared"

- Bottom menu
    - Set Up: Opens a pop-up menu with the following options:
        - Display (Opens Display settings)
        - Audio (Opens Audio settings)
        - Keyboard (Opens Keyboard settings)
    - Map: Opens the maps popup menu
    - Info: Opens the Info popup menu
    - Second: Opens a new Air window
    - Sup ASD: Disabled, reserved for future use
    - FPL: Opens the flight plan window, same as Windows -> Flight Plan would
    - HLD SET: Opens the Hold Setup window from the Hold Plugin.
    - SSTP: Opens the Strip Setup window, same as Settings -> Strips -> Setup
    - The letter below shows the strip display mode, either:
        - A: Alpha
        - T: Time
        - L: Level
    - Lost: Disabled, reserved for future use.
    - TFMS: Opens the TFMS popup menu, same as the TFMS menu item in the default menu bar.
    - TFC MGT: Disabled, reserved for future use.
    - CQ: Disabled, reserved for future use.
    - ADS Contract: Opens the ADS Contract window from the CPDLC Plugin.
    - History CPDLC: Opens the CPDLC History window from the CPDLC Plugin.
    - WAYP: Disabled, reserved for future use.
    - Tag List: Disabled, reserved for future use.
    - Del Tag: Disabled, reserved for future use.
    - Rad Tag: Disabled, reserved for future use.
    - LATC: Disabled, reserved for future use.
